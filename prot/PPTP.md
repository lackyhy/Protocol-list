**PPTP** (Point-to-Point Tunneling Protocol) — один из первых VPN-протоколов, разработанный консорциумом во главе с Microsoft в 1990-х. PPTP туннелирует PPP через IP с помощью управляющего TCP-соединения и модифицированного GRE. Протокол прост и быстр, но его защита (MS-CHAPv2 + MPPE) давно взломана, поэтому **PPTP считается небезопасным** и удалён из современных версий iOS и macOS.

## **Основные характеристики**

| Параметр                    | Описание                                                                 |
| --------------------------- | ------------------------------------------------------------------------ |
| **Уровень OSI**             | Канальный (туннелирует PPP)                                              |
| **Управляющий канал**       | TCP 1723                                                                 |
| **Канал данных**            | Enhanced GRE (IP протокол 47, версия GRE 1)                              |
| **Стандарт**                | RFC 2637 (информационный)                                                |
| **Аутентификация**          | PPP: PAP, CHAP, MS-CHAPv1, MS-CHAPv2, EAP-TLS                            |
| **Шифрование**              | MPPE (RC4, 40/56/128 бит)                                                |
| **Статус**                  | Небезопасен, устарел                                                     |

## **Как работает PPTP**

PPTP использует два канала:

```
Клиент (PAC)                                      Сервер (PNS)
    |                                                  |
    |=== Управление: TCP 1723 =======================>|
    |--- Start-Control-Connection-Request ----------->|
    |<-- Start-Control-Connection-Reply --------------|
    |--- Outgoing-Call-Request ---------------------->|
    |<-- Outgoing-Call-Reply (Call ID) ---------------|
    |                                                  |
    |=== Данные: GRE (протокол 47) ===================>|
    |--- PPP LCP ------------------------------------->|
    |--- PPP аутентификация (MS-CHAPv2) -------------->|
    |--- PPP CCP (согласование MPPE) ----------------->|
    |--- PPP IPCP (IP-адрес) ------------------------->|
    |<================ Зашифрованные PPP-кадры =======>|
```

| Термин     | Описание                                              |
| ---------- | ----------------------------------------------------- |
| **PAC**    | PPTP Access Concentrator — клиент / сторона доступа   |
| **PNS**    | PPTP Network Server — VPN-сервер                      |

## **Управляющие сообщения (TCP 1723)**

| Код | Сообщение                          | Описание                              |
| --- | ---------------------------------- | ------------------------------------- |
| 1   | Start-Control-Connection-Request   | Начало управляющего соединения        |
| 2   | Start-Control-Connection-Reply     | Ответ                                 |
| 3   | Stop-Control-Connection-Request    | Закрытие                              |
| 4   | Stop-Control-Connection-Reply      | Ответ на закрытие                     |
| 5   | Echo-Request                       | Keepalive                             |
| 6   | Echo-Reply                         | Ответ на keepalive                    |
| 7   | Outgoing-Call-Request              | Создание сессии                       |
| 8   | Outgoing-Call-Reply                | Ответ с Call ID                       |
| 9   | Incoming-Call-Request              | Входящий вызов                        |
| 10  | Incoming-Call-Reply                | Ответ                                 |
| 11  | Incoming-Call-Connected            | Подтверждение                         |
| 12  | Call-Clear-Request                 | Запрос на закрытие сессии             |
| 13  | Call-Disconnect-Notify             | Уведомление о закрытии                |
| 14  | WAN-Error-Notify                   | Ошибка                                |
| 15  | Set-Link-Info                      | Параметры PPP                         |

## **Инкапсуляция данных**

```
| IP (proto 47) | Enhanced GRE (ver 1, Call ID) | PPP | MPPE (зашифр.) | Исходный IP | Data |
```

Enhanced GRE отличается от обычного: есть поле **Call ID** для различения сессий и поля **Sequence/Acknowledgment** для управления потоком.

## **Почему PPTP небезопасен**

| Уязвимость                         | Описание                                                       |
| ---------------------------------- | -------------------------------------------------------------- |
| **MS-CHAPv2 сводится к DES**       | Хэш пароля можно получить, взломав один ключ DES (56 бит). В 2012 году (Moxie Marlinspike, CloudCracker) — за сутки, сейчас быстрее |
| **Ключ MPPE выводится из пароля**  | Взлом аутентификации = расшифровка всего трафика               |
| **RC4**                            | Устаревший потоковый шифр с известными слабостями              |
| **Нет целостности**                | Пакеты можно модифицировать (bit-flipping)                     |
| **Нет аутентификации сервера**     | MITM с поддельным сервером                                     |
| **Управляющий канал не шифруется** | Видны имена пользователей и параметры                          |

Microsoft с 2012 года рекомендует не использовать PPTP. Apple удалила PPTP из iOS 10 и macOS Sierra (2016). Единственный относительно безопасный вариант — PPTP с **EAP-TLS**, но тогда проще сразу выбрать другой протокол.

## **Проблемы с NAT и файрволами**

- GRE не имеет портов, поэтому NAT должен отслеживать **Call ID** — нужна функция **PPTP passthrough** / PPTP ALG
- Многие провайдеры и сети блокируют протокол 47
- Обнаруживается и блокируется DPI тривиально

## **Примеры использования**

### **Сервер на Linux (pptpd) — только для тестов и legacy**

```
# /etc/pptpd.conf
localip 10.9.0.1
remoteip 10.9.0.10-100

# /etc/ppp/pptpd-options
require-mschap-v2
require-mppe-128
ms-dns 1.1.1.1

# /etc/ppp/chap-secrets
alice  pptpd  password  *
```

### **Клиент Linux**

```bash
pptpsetup --create office --server vpn.example.com --username alice --password secret --encrypt
pon office
poff office
```

### **Windows**

```powershell
Add-VpnConnection -Name "Legacy" -ServerAddress "vpn.example.com" -TunnelType Pptp -EncryptionLevel Required
```

### **Файрвол (iptables)**

```bash
iptables -A INPUT -p tcp --dport 1723 -j ACCEPT
iptables -A INPUT -p gre -j ACCEPT
modprobe nf_conntrack_pptp   # ALG для NAT
```

### **Wireshark**

```
pptp
gre && gre.proto == 0x880b
```

## **Где ещё встречается PPTP**

1. **Старое оборудование** — роутеры и NAS без других вариантов VPN
2. **Некоторые провайдеры** — исторически использовали PPTP для подключения абонентов
3. **Обход блокировок** — устаревшие VPN-сервисы (небезопасно)

## **Чем заменить**

| Задача                            | Замена                         |
| --------------------------------- | ------------------------------ |
| Встроенный VPN-клиент в ОС        | IKEv2/IPsec, L2TP/IPsec        |
| Максимальная скорость и простота  | WireGuard                      |
| Гибкость, проход через файрволы   | OpenVPN, SSTP (Windows)        |
| Корпоративный удалённый доступ    | IKEv2 с сертификатами, SSL VPN |

## **Сравнение PPTP и L2TP/IPsec**

| Характеристика      | PPTP                  | L2TP/IPsec                  |
| ------------------- | --------------------- | --------------------------- |
| **Шифрование**      | MPPE (RC4)            | IPsec (AES)                 |
| **Безопасность**    | Взломан               | Приемлемая                  |
| **Целостность данных** | Нет                | Да                          |
| **Скорость**        | Высокая               | Ниже (двойная инкапсуляция) |
| **Порты**           | TCP 1723 + GRE        | UDP 500, 4500 + ESP         |
| **NAT**             | Нужен ALG             | NAT-T                       |
| **Поддержка в ОС**  | Удаляется             | Встроен                     |
