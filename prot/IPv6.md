**IPv6** (Internet Protocol version 6) — шестая версия протокола IP, пришедшая на смену IPv4. Главная причина появления — исчерпание 32-битного адресного пространства IPv4. IPv6 использует 128-битные адреса, упрощённый заголовок, встроенную автоконфигурацию и обязательную поддержку многоадресной рассылки.

## **Основные характеристики**

| Параметр                    | Описание                                                                 |
| --------------------------- | ------------------------------------------------------------------------ |
| **Уровень OSI**             | Сетевой (Network Layer)                                                  |
| **Стандарт**                | RFC 8200 (ранее RFC 2460)                                                |
| **Размер адреса**           | 128 бит (≈ 3,4 × 10³⁸ адресов)                                           |
| **Размер заголовка**        | Фиксированный, 40 байт                                                   |
| **EtherType**               | `0x86DD`                                                                 |
| **Разрешение адресов**      | NDP (вместо ARP)                                                         |
| **Служебные сообщения**     | ICMPv6                                                                   |
| **Широковещание**           | Отсутствует — заменено multicast                                         |

## **Формат адреса**

Адрес записывается как 8 групп по 4 шестнадцатеричных цифры, разделённых двоеточием:

```
2001:0db8:0000:0000:0000:ff00:0042:8329
```

### **Правила сокращения**

1. Ведущие нули в группе можно опускать: `0db8` → `db8`
2. Одну непрерывную последовательность нулевых групп можно заменить на `::` (только один раз в адресе)

```
2001:0db8:0000:0000:0000:ff00:0042:8329
2001:db8:0:0:0:ff00:42:8329
2001:db8::ff00:42:8329
```

### **Префикс**

Длина префикса указывается через `/`, как CIDR в IPv4:

```
2001:db8:abcd:12::/64
```

Стандартный размер подсети — **/64**: первые 64 бита — префикс сети, последние 64 бита — идентификатор интерфейса (Interface ID).

## **Типы адресов**

| Тип                     | Префикс          | Описание                                                       |
| ----------------------- | ---------------- | -------------------------------------------------------------- |
| **Global Unicast (GUA)** | `2000::/3`      | Публичные маршрутизируемые адреса                              |
| **Link-Local**          | `fe80::/10`      | Действуют только в пределах сегмента, есть у каждого интерфейса |
| **Unique Local (ULA)**  | `fc00::/7` (`fd00::/8` на практике) | Аналог частных адресов IPv4 (10.0.0.0/8 и т.д.) |
| **Multicast**           | `ff00::/8`       | Групповая рассылка                                             |
| **Loopback**            | `::1/128`        | Аналог 127.0.0.1                                               |
| **Unspecified**         | `::/128`         | Аналог 0.0.0.0                                                 |
| **IPv4-mapped**         | `::ffff:0:0/96`  | IPv4-адрес внутри IPv6 (`::ffff:192.0.2.1`)                    |
| **Documentation**       | `2001:db8::/32`  | Для примеров в документации                                    |
| **6to4**                | `2002::/16`      | Устаревший механизм туннелирования                             |

**Anycast** — отдельного префикса нет: это обычный unicast-адрес, назначенный нескольким узлам; пакет доставляется ближайшему.

### **Важные multicast-адреса**

| Адрес          | Назначение                                  |
| -------------- | ------------------------------------------- |
| `ff02::1`      | Все узлы в сегменте                         |
| `ff02::2`      | Все маршрутизаторы в сегменте               |
| `ff02::5`      | OSPFv3 маршрутизаторы                       |
| `ff02::9`      | RIPng маршрутизаторы                        |
| `ff02::a`      | EIGRP маршрутизаторы                        |
| `ff02::1:2`    | DHCPv6 серверы и relay-агенты               |
| `ff02::fb`     | mDNS                                        |
| `ff02::1:ffXX:XXXX` | Solicited-Node (используется NDP)      |

## **Структура заголовка IPv6**

| Поле                    | Размер (биты) | Описание                                                  |
| ----------------------- | ------------- | --------------------------------------------------------- |
| **Version**             | 4             | Версия протокола (6)                                      |
| **Traffic Class**       | 8             | Класс трафика (DSCP + ECN), аналог ToS                    |
| **Flow Label**          | 20            | Метка потока для QoS и балансировки                       |
| **Payload Length**      | 16            | Длина данных после основного заголовка                    |
| **Next Header**         | 8             | Тип следующего заголовка (6 = TCP, 17 = UDP, 58 = ICMPv6) |
| **Hop Limit**           | 8             | Аналог TTL                                                |
| **Source Address**      | 128           | Адрес отправителя                                         |
| **Destination Address** | 128           | Адрес получателя                                          |

**Общий размер:** 40 байт (фиксированный)

### **Что убрали по сравнению с IPv4**

- **Header Checksum** — контрольная сумма есть на канальном и транспортном уровнях
- **Фрагментация на маршрутизаторах** — фрагментирует только отправитель
- **Options** — заменены цепочкой Extension Headers
- **IHL** — заголовок всегда 40 байт

## **Extension Headers (заголовки расширения)**

Дополнительные функции вынесены в отдельные заголовки, которые выстраиваются в цепочку через поле **Next Header**:

| Значение | Заголовок                   | Назначение                                 |
| -------- | --------------------------- | ------------------------------------------ |
| 0        | Hop-by-Hop Options          | Обрабатывается каждым маршрутизатором      |
| 43       | Routing                     | Маршрутизация от источника (SRv6)          |
| 44       | Fragment                    | Фрагментация                               |
| 50       | ESP                         | Шифрование IPsec                           |
| 51       | AH                          | Аутентификация IPsec                       |
| 60       | Destination Options         | Опции для получателя                       |
| 59       | No Next Header              | Конец цепочки                              |

```
| IPv6 Header | Hop-by-Hop | Routing | Fragment | TCP Header | Data |
  NH=0          NH=43        NH=44     NH=6
```

## **Автоконфигурация адресов**

### **SLAAC (Stateless Address Autoconfiguration)**

```
1. Узел создаёт link-local адрес fe80::/64 + Interface ID
2. Проверяет уникальность адреса (DAD — Duplicate Address Detection)
3. Отправляет Router Solicitation на ff02::2
4. Маршрутизатор отвечает Router Advertisement с префиксом (например, 2001:db8:1::/64)
5. Узел формирует глобальный адрес: префикс + Interface ID
```

### **Способы формирования Interface ID**

| Способ                    | Описание                                                 |
| ------------------------- | -------------------------------------------------------- |
| **EUI-64**                | Из MAC-адреса (вставка `fffe` и инверсия 7-го бита)      |
| **Privacy Extensions**    | Случайный временный адрес (RFC 8981), меняется периодически |
| **Stable Privacy**        | Стабильный, но непредсказуемый адрес (RFC 7217)          |
| **DHCPv6**                | Выдаётся сервером                                        |
| **Вручную**               | Статическая настройка                                    |

**Пример EUI-64:**
```
MAC:          00:1A:2B:3C:4D:5E
Разделить:    001A2B   3C4D5E
Вставить fffe: 001A2B FFFE 3C4D5E
Инвертировать 7-й бит: 021A:2BFF:FE3C:4D5E
Адрес:        fe80::21a:2bff:fe3c:4d5e
```

### **DHCPv6**

| Режим                     | Описание                                                 |
| ------------------------- | -------------------------------------------------------- |
| **Stateless DHCPv6**      | Адрес через SLAAC, DNS и прочие опции — через DHCPv6     |
| **Stateful DHCPv6**       | Адрес выдаёт сервер (аналог DHCP в IPv4)                 |
| **Prefix Delegation**     | Провайдер выдаёт роутеру целый префикс (например, /56)   |

Режим определяется флагами **M** (Managed) и **O** (Other) в Router Advertisement. Порты DHCPv6: клиент — UDP 546, сервер — UDP 547.

## **Фрагментация и MTU**

- Минимальный MTU в IPv6 — **1280 байт**
- Маршрутизаторы **не фрагментируют** пакеты
- Если пакет больше MTU канала, маршрутизатор отбрасывает его и отправляет ICMPv6 **Packet Too Big**
- Отправитель использует **Path MTU Discovery** и при необходимости фрагментирует сам (Fragment Header)

## **Механизмы перехода с IPv4**

| Механизм           | Тип          | Описание                                                    |
| ------------------ | ------------ | ----------------------------------------------------------- |
| **Dual Stack**     | Параллельно  | Узел работает одновременно с IPv4 и IPv6                    |
| **6in4**           | Туннель      | IPv6 внутри IPv4 (протокол 41)                              |
| **6to4**           | Туннель      | Автоматический туннель, устарел                             |
| **Teredo**         | Туннель      | IPv6 через UDP поверх NAT, устарел                          |
| **6rd**            | Туннель      | Вариант 6to4 с префиксом провайдера                         |
| **NAT64 + DNS64**  | Трансляция   | Доступ IPv6-only клиентов к IPv4-ресурсам                   |
| **464XLAT**        | Трансляция   | IPv4 поверх IPv6-only сети (часто в мобильных сетях)        |
| **DS-Lite**        | Туннель      | IPv4 в IPv6 до CGNAT провайдера                             |

## **Примеры использования**

### **Просмотр адресов**

```bash
# Linux
ip -6 addr show
ip -6 route show

# Windows
ipconfig
netsh interface ipv6 show addresses

# macOS
ifconfig | grep inet6
```

### **Проверка связности**

```bash
# Linux / macOS
ping -6 google.com
ping6 2001:4860:4860::8888
traceroute -6 google.com

# Windows
ping -6 google.com
tracert -6 google.com
```

### **Настройка статического адреса (Linux)**

```bash
ip -6 addr add 2001:db8:1::10/64 dev eth0
ip -6 route add default via 2001:db8:1::1
```

### **Включение маршрутизации (Linux)**

```bash
sysctl -w net.ipv6.conf.all.forwarding=1
```

### **Cisco IOS**

```
ipv6 unicast-routing
interface GigabitEthernet0/0
 ipv6 address 2001:db8:1::1/64
 ipv6 address fe80::1 link-local
 no shutdown
```

### **Подключение к адресу в URL**

IPv6-адрес в URL заключается в квадратные скобки:

```
http://[2001:db8::1]:8080/
ssh user@2001:db8::1
```

## **Безопасность IPv6**

### **Угрозы**

1. **Rogue Router Advertisement** — поддельный роутер раздаёт свой префикс и шлюз
2. **NDP Spoofing** — аналог ARP Spoofing
3. **Обход фильтров** — правила файрвола настроены только для IPv4, а IPv6 открыт
4. **Туннели** — 6to4/Teredo могут обходить периметр
5. **Extension Headers** — используются для обхода IDS и DoS
6. **Отслеживание по EUI-64** — MAC-адрес «виден» в адресе

### **Защита**

- **RA Guard** на коммутаторах
- **DHCPv6 Guard** и **ND Inspection**
- Отдельные правила `ip6tables` / `nftables` для IPv6
- Отключение неиспользуемых туннелей
- Privacy Extensions на клиентах
- IPsec (поддержка была обязательной в ранних RFC, сейчас рекомендуемая)

## **Сравнение с IPv4**

| Характеристика       | IPv4                       | IPv6                              |
| -------------------- | -------------------------- | --------------------------------- |
| **Размер адреса**    | 32 бита                    | 128 бит                           |
| **Запись**           | Десятичная, `192.168.1.1`  | Шестнадцатеричная, `2001:db8::1`  |
| **Заголовок**        | 20–60 байт                 | 40 байт фиксированно              |
| **Контрольная сумма** | Есть                      | Нет                               |
| **Фрагментация**     | Отправитель и маршрутизаторы | Только отправитель              |
| **Широковещание**    | Есть (broadcast)           | Нет, только multicast             |
| **Разрешение адресов** | ARP                      | NDP (ICMPv6)                      |
| **Автоконфигурация** | DHCP                       | SLAAC и/или DHCPv6                |
| **NAT**              | Повсеместно                | Обычно не нужен                   |
| **Минимальный MTU**  | 576 байт                   | 1280 байт                         |
| **IPsec**            | Опционально                | Встроенная поддержка              |
