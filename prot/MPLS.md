**MPLS** (Multiprotocol Label Switching) — технология передачи пакетов по меткам вместо поиска по IP-адресу назначения. На входе в сеть пакету назначается короткая метка, и дальше маршрутизаторы переключают его по таблице меток. MPLS — основа сетей провайдеров: на нём строятся L3VPN и L2VPN для корпоративных клиентов, Traffic Engineering и быстрое восстановление при отказах.

## **Основные характеристики**

| Параметр                    | Описание                                                                 |
| --------------------------- | ------------------------------------------------------------------------ |
| **Уровень OSI**             | Между канальным и сетевым («уровень 2,5»)                                |
| **Стандарт**                | RFC 3031 (архитектура), RFC 3032 (метки)                                 |
| **EtherType**               | `0x8847` (unicast), `0x8848` (multicast)                                 |
| **Размер метки**            | 4 байта (20 бит — значение метки)                                        |
| **Распределение меток**     | LDP, RSVP-TE, BGP, Segment Routing                                       |
| **Назначение**              | VPN, Traffic Engineering, быстрая коммутация, QoS                        |

## **Структура метки (Label Stack Entry)**

```
| Ethernet Header | MPLS Label(s) | IP Header | Data |
```

| Поле             | Размер (биты) | Описание                                        |
| ---------------- | ------------- | ----------------------------------------------- |
| **Label**        | 20            | Значение метки (0–1 048 575)                    |
| **TC (EXP)**     | 3             | Traffic Class — приоритет (QoS)                 |
| **S (Bottom of Stack)** | 1      | 1 = последняя метка в стеке                     |
| **TTL**          | 8             | Время жизни                                     |

Пакет может нести **стек меток**: внешняя — транспорт через сеть провайдера, внутренняя — идентификатор VPN или сервиса.

### **Зарезервированные метки**

| Метка | Название                  | Назначение                                     |
| ----- | ------------------------- | ---------------------------------------------- |
| 0     | IPv4 Explicit NULL        | Снять метку, сохранить TC                      |
| 1     | Router Alert              | Обработать пакет на CPU                        |
| 2     | IPv6 Explicit NULL        | То же для IPv6                                 |
| 3     | Implicit NULL             | Сигнал для Penultimate Hop Popping (в пакетах не встречается) |
| 13    | GAL                       | Generic Associated Channel (OAM)               |
| 14    | OAM Alert                 | OAM                                            |

## **Роли маршрутизаторов**

| Роль               | Описание                                                       |
| ------------------ | -------------------------------------------------------------- |
| **LSR**            | Label Switching Router — любой маршрутизатор с MPLS            |
| **LER / PE**       | Edge-маршрутизатор: навешивает (push) и снимает (pop) метки    |
| **P (Provider)**   | Транзитный маршрутизатор ядра — только меняет метки (swap)     |
| **CE (Customer Edge)** | Маршрутизатор клиента, MPLS не знает                       |

## **Операции с метками**

| Операция | Описание                                    | Где выполняется        |
| -------- | ------------------------------------------- | ---------------------- |
| **Push** | Добавить метку                              | Входной PE (ingress)   |
| **Swap** | Заменить метку на другую                    | P-маршрутизаторы       |
| **Pop**  | Снять метку                                 | Предпоследний или выходной узел |

### **Путь пакета (LSP — Label Switched Path)**

```
CE-A ── PE1 ─────── P1 ─────── P2 ─────── PE2 ── CE-B
        push 100    swap       pop (PHP)   IP lookup
        IP→[100]    100→200    200→ (нет)
```

**PHP (Penultimate Hop Popping)** — предпоследний маршрутизатор снимает метку, чтобы выходной PE не делал двойной поиск.

## **Основные понятия**

| Понятие       | Описание                                                          |
| ------------- | ----------------------------------------------------------------- |
| **FEC**       | Forwarding Equivalence Class — группа пакетов с одинаковой обработкой (например, один префикс) |
| **LSP**       | Однонаправленный путь пакетов с метками                           |
| **LIB**       | Label Information Base — все полученные метки                     |
| **LFIB**      | Label Forwarding Information Base — таблица коммутации меток      |

## **Протоколы распределения меток**

| Протокол                  | Описание                                                    |
| ------------------------- | ----------------------------------------------------------- |
| **LDP** (RFC 5036)        | Метки для префиксов из IGP, TCP/UDP 646                     |
| **RSVP-TE** (RFC 3209)    | Явные пути с резервированием полосы (Traffic Engineering)   |
| **MP-BGP**                | Метки для VPN-префиксов (L3VPN), EVPN                       |
| **Segment Routing (SR-MPLS)** | Метки распространяются через IGP (IS-IS/OSPF), LDP и RSVP не нужны |

## **Сервисы на базе MPLS**

### **L3VPN (RFC 4364)**

Провайдер маршрутизирует трафик клиента; сети разных клиентов изолированы даже при совпадающих адресах.

| Компонент            | Описание                                                   |
| -------------------- | ---------------------------------------------------------- |
| **VRF**              | Отдельная таблица маршрутизации на PE для каждого клиента  |
| **RD (Route Distinguisher)** | Делает префикс уникальным: `65000:1:10.0.0.0/24`   |
| **RT (Route Target)** | Какие маршруты импортировать/экспортировать в VRF         |
| **MP-BGP (VPNv4)**   | Обмен маршрутами клиентов между PE                         |

```
Стек меток в L3VPN:
| Eth | Транспортная метка (LDP) | VPN-метка (BGP) | IP клиента | Data |
```

### **L2VPN**

| Тип          | Описание                                             |
| ------------ | ---------------------------------------------------- |
| **VPWS (Pseudowire)** | Точка-точка, «виртуальный кабель»            |
| **VPLS**     | Многоточечный L2 — «виртуальный коммутатор»          |
| **EVPN**     | Современный L2/L3 VPN через BGP, заменяет VPLS        |

### **Traffic Engineering**

- Направление трафика не по кратчайшему пути, а с учётом загрузки каналов
- **Fast Reroute (FRR)** — переключение на резервный путь за < 50 мс
- Гарантия полосы для критичных сервисов

## **Примеры конфигурации**

### **Cisco IOS — MPLS с LDP**

```
mpls label protocol ldp
mpls ldp router-id Loopback0 force

interface GigabitEthernet0/0
 ip address 10.0.12.1 255.255.255.252
 mpls ip
```

### **Cisco IOS — L3VPN (PE)**

```
vrf definition CUSTOMER_A
 rd 65000:1
 address-family ipv4
  route-target export 65000:1
  route-target import 65000:1

interface GigabitEthernet0/1
 vrf forwarding CUSTOMER_A
 ip address 172.16.1.1 255.255.255.0

router bgp 65000
 neighbor 2.2.2.2 remote-as 65000
 neighbor 2.2.2.2 update-source Loopback0
 address-family vpnv4
  neighbor 2.2.2.2 activate
  neighbor 2.2.2.2 send-community extended
 address-family ipv4 vrf CUSTOMER_A
  redistribute connected
```

### **Проверка**

```
show mpls interfaces
show mpls ldp neighbor
show mpls forwarding-table
show ip route vrf CUSTOMER_A
show bgp vpnv4 unicast all
traceroute mpls ipv4 2.2.2.2/32
```

### **Linux**

```bash
modprobe mpls_router mpls_iptunnel
sysctl -w net.mpls.platform_labels=100000
sysctl -w net.mpls.conf.eth0.input=1

# Push метки 100 для префикса
ip route add 10.10.0.0/24 encap mpls 100 via 192.168.1.2

# Swap 100 → 200
ip -f mpls route add 100 as 200 via inet 192.168.2.2

ip -f mpls route show
```

FRRouting поддерживает LDP, BGP L3VPN и Segment Routing.

```

```

## **Безопасность MPLS**

- MPLS VPN обеспечивает **изоляцию**, но **не шифрование** — данные клиента идут открыто внутри сети провайдера
- Для конфиденциальности поверх MPLS используют IPsec или MACsec
- Защита от внешних меток: PE не должен принимать пакеты с метками от CE
- Аутентификация LDP (TCP-AO/MD5) и BGP

## **Сравнение MPLS L3VPN, IPsec VPN и SD-WAN**

| Характеристика       | MPLS L3VPN            | IPsec VPN поверх интернета | SD-WAN                  |
| -------------------- | --------------------- | -------------------------- | ----------------------- |
| **Гарантия качества** | SLA провайдера       | Нет                        | Частично (несколько каналов) |
| **Шифрование**       | Нет                   | Да                         | Да                      |
| **Стоимость**        | Высокая               | Низкая                     | Средняя                 |
| **Управление**       | Провайдер             | Клиент                     | Централизованное        |
| **Задержка**         | Предсказуемая         | Зависит от интернета       | Динамический выбор пути |
