**VLAN** (Virtual Local Area Network) — технология логического разделения одной физической сети на несколько изолированных широковещательных доменов. Стандарт **IEEE 802.1Q** описывает, как метка VLAN добавляется в Ethernet-кадр, чтобы по одному кабелю (транку) можно было передавать трафик многих VLAN.

## **Основные характеристики**

| Параметр                    | Описание                                                                 |
| --------------------------- | ------------------------------------------------------------------------ |
| **Уровень OSI**             | Канальный (Data Link Layer)                                              |
| **Стандарт**                | IEEE 802.1Q                                                              |
| **TPID (EtherType метки)**  | `0x8100` (802.1Q), `0x88A8` (802.1ad, Q-in-Q)                            |
| **Размер метки**            | 4 байта                                                                  |
| **Диапазон VLAN ID**        | 1–4094 (0 и 4095 зарезервированы)                                        |
| **Назначение**              | Сегментация сети, изоляция трафика, безопасность                         |

## **Зачем нужны VLAN**

1. **Изоляция** — бухгалтерия, гости и серверы в разных сетях на одном коммутаторе
2. **Безопасность** — трафик между VLAN проходит только через маршрутизатор/файрвол
3. **Уменьшение broadcast-домена** — меньше лишнего трафика
4. **Гибкость** — сотрудник переезжает, VLAN остаётся прежним
5. **Экономия** — не нужно отдельное оборудование для каждой сети

## **Структура метки 802.1Q**

Метка вставляется в Ethernet-кадр между MAC-адресом источника и полем EtherType:

```
Обычный кадр:
| Dst MAC | Src MAC | EtherType | Data | FCS |

Кадр с меткой 802.1Q:
| Dst MAC | Src MAC | 802.1Q Tag (4 байта) | EtherType | Data | FCS |
```

| Поле                    | Размер (биты) | Описание                                               |
| ----------------------- | ------------- | ------------------------------------------------------ |
| **TPID**                | 16            | Tag Protocol Identifier, `0x8100`                      |
| **PCP**                 | 3             | Priority Code Point — приоритет (802.1p, QoS), 0–7     |
| **DEI**                 | 1             | Drop Eligible Indicator — можно отбросить при перегрузке |
| **VID**                 | 12            | VLAN Identifier, 0–4095                                |

Максимальный размер кадра увеличивается с 1518 до **1522 байт**.

### **Приоритеты 802.1p (PCP)**

| PCP | Класс трафика                |
| --- | ---------------------------- |
| 0   | Best Effort (по умолчанию)   |
| 1   | Background (самый низкий)    |
| 2   | Excellent Effort             |
| 3   | Critical Applications        |
| 4   | Video                        |
| 5   | Voice                        |
| 6   | Internetwork Control         |
| 7   | Network Control (самый высокий) |

## **Типы портов**

| Тип порта         | Описание                                                                    |
| ----------------- | --------------------------------------------------------------------------- |
| **Access**        | Принадлежит одному VLAN. Кадры передаются без метки. Подключаются ПК, принтеры |
| **Trunk**         | Передаёт кадры многих VLAN с метками. Между коммутаторами, к роутерам, гипервизорам |
| **Hybrid** (некоторые вендоры) | Несколько VLAN, часть с метками, часть без                     |

### **Native VLAN**

На trunk-порту трафик **native VLAN** передаётся **без метки**. По умолчанию это VLAN 1. Native VLAN должен совпадать на обоих концах транка.

### **Специальные VLAN**

| VLAN ID      | Назначение                                     |
| ------------ | ---------------------------------------------- |
| 0            | Метка только с приоритетом (priority tag)      |
| 1            | VLAN по умолчанию (не рекомендуется использовать для данных) |
| 1002–1005    | Зарезервированы у Cisco (Token Ring, FDDI)     |
| 1006–4094    | Расширенный диапазон                           |
| 4095         | Зарезервирован                                 |

## **Маршрутизация между VLAN (Inter-VLAN Routing)**

Устройства в разных VLAN не видят друг друга без маршрутизатора.

| Способ                  | Описание                                                       |
| ----------------------- | -------------------------------------------------------------- |
| **Router-on-a-stick**   | Один trunk-порт роутера, подынтерфейсы на каждый VLAN          |
| **L3-коммутатор (SVI)** | Виртуальный интерфейс VLAN на самом коммутаторе                |
| **Отдельные порты**     | Каждый VLAN в отдельный физический порт роутера (устарело)     |

```
           Router (Gi0/0.10, Gi0/0.20)
              |  trunk
          Switch
         /       \
   VLAN 10      VLAN 20
   (ПК бухгалтерии) (ПК разработчиков)
```

## **Q-in-Q (802.1ad)**

Двойная метка: провайдер добавляет свою внешнюю метку (S-Tag) поверх меток клиента (C-Tag). Позволяет передавать VLAN клиентов через сеть провайдера без конфликтов.

```
| Dst MAC | Src MAC | S-Tag 0x88A8 | C-Tag 0x8100 | EtherType | Data | FCS |
```

## **Протоколы управления VLAN**

| Протокол | Описание                                                       |
| -------- | -------------------------------------------------------------- |
| **VTP**  | VLAN Trunking Protocol (Cisco) — синхронизация списка VLAN     |
| **DTP**  | Dynamic Trunking Protocol (Cisco) — автоматическое согласование транка |
| **GVRP / MVRP** | Стандартная (IEEE) динамическая регистрация VLAN       |

## **Примеры конфигурации**

### **Cisco IOS — access и trunk**

```
vlan 10
 name ACCOUNTING
vlan 20
 name DEV

interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 10

interface GigabitEthernet0/24
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 switchport trunk native vlan 999
 switchport nonegotiate
```

### **Cisco IOS — router-on-a-stick**

```
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
```

### **Cisco IOS — SVI на L3-коммутаторе**

```
ip routing
interface Vlan10
 ip address 192.168.10.1 255.255.255.0
interface Vlan20
 ip address 192.168.20.1 255.255.255.0
```

### **Linux**

```bash
# Создать VLAN-интерфейс
ip link add link eth0 name eth0.10 type vlan id 10
ip addr add 192.168.10.5/24 dev eth0.10
ip link set eth0.10 up

# Просмотр
ip -d link show eth0.10
cat /proc/net/vlan/config
```

### **Проверка на Cisco**

```
show vlan brief
show interfaces trunk
show interfaces Gi0/1 switchport
```

### **Wireshark**

```
vlan
vlan.id == 10
```

## **Безопасность VLAN**

### **Атаки**

| Атака                  | Описание                                                             |
| ---------------------- | -------------------------------------------------------------------- |
| **Switch Spoofing**    | Атакующий согласует trunk через DTP и получает доступ ко всем VLAN   |
| **Double Tagging**     | Кадр с двумя метками: внешняя = native VLAN, снимается первым коммутатором, внутренняя ведёт в чужой VLAN |
| **VLAN Hopping**       | Общее название для двух атак выше                                    |

### **Защита**

- Отключить DTP: `switchport nonegotiate`, явно задавать `mode access` / `mode trunk`
- Не использовать VLAN 1 для данных
- Native VLAN — отдельный неиспользуемый VLAN (например, 999)
- Ограничить список VLAN на транке (`allowed vlan`)
- Неиспользуемые порты — в выключенный «мусорный» VLAN
- Private VLAN для изоляции хостов в одном VLAN

## **Сравнение VLAN и VXLAN**

| Характеристика      | VLAN (802.1Q)      | VXLAN                         |
| ------------------- | ------------------ | ----------------------------- |
| **Уровень**         | L2                 | L2 поверх L3 (UDP)            |
| **Количество сетей** | 4094              | ~16 миллионов (24-битный VNI) |
| **Границы**         | Одна L2-сеть       | Через маршрутизируемую сеть   |
| **Применение**      | Офисы, кампусы     | Дата-центры, облака           |
